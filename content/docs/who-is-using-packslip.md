# Who is using Packslip

to a concrete release and its signature bundle, so you can inspect examples
of the format in use.

As of **13 October 2026**, this list covers **50 tools**: **43 upstream-published**
and **7 independently published**. It is a snapshot of discovered published
manifests, not an exhaustive census or a count of installed users. Proposed
integrations and merged changes that have not shipped a manifest are excluded.

## About this snapshot

The linked bundles were checked against their GitHub release asset SHA-256
digests and verified with Packslip 1.7.0 against the publisher's certificate
source repository and the GitHub Actions issuer. This verifies the manifest
signatures; it is not a complete audit of the listed binary artifacts or
linked build attestations. A listing is publication evidence, not an
endorsement of the software.

To publish your own release manifest, start with
[Publish with GitHub Actions](/docs/publishing/). To inspect one of these
bundles, see [Verify a release](/docs/verifying/).
