# Bundled font

`SpaceGrotesk.ttf` supplies Space Grotesk for the site's
[social previews](../README.md). Bundling it makes image generation
deterministic and avoids relying on system fonts or network access during
the build.

- Source: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/spacegrotesk)
- License: SIL Open Font License 1.1, included in `OFL.txt`
